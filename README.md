### ⚡ D Flip-Flop Timing & Metastability Analysis

Studying the timing behavior of a transmission-gate based D latch / flip-flop, including **setup time, hold time, contamination delay, clock-to-Q delay, and metastability**.

**Focus:**  
`CMOS` `LTspice` `Digital Design` `Timing Analysis`
